    65→### API — milik 3-a (CHAT)
    66→- `GET /api/chats?filter=all|unread|groups|archived&q=` → `{ chats: [...] }` tiap item: id, type (PRIVATE|GROUP), name, avatarUrl, colorKey, pinned, archived, muted, unread, isBusinessChat, lastMessageAt, contact{id,name,phone,colorKey,lastSeen,blocked,about,labelIds}|null, members (JSON string), groupDesc, lastMessage {type, body, sender, status, createdAt}|null. Urut pinned dulu lalu lastMessageAt desc. `q` mencari nama kontak/nama grup & isi pesan.
    67→- `POST /api/chats` — PRIVATE: `{ type:"PRIVATE", contactId }` (pakai chat lama jika sudah ada, kembalikan yang ada; chat baru otomatis dapat pesan SYSTEM greeting jika profile.greetingEnabled). GROUP: `{ type:"GROUP", name, memberIds:[...], groupDesc? }`. → `{ chat }`.
    68→- `PATCH /api/chats/[id]` `{ pinned?, archived?, muted?, unread? (angka), name?, groupDesc? }` → `{ chat }`.
    69→- `DELETE /api/chats/[id]` → hapus chat+pesan → `{ success: true }`.
    70→- `GET /api/chats/[id]/messages` → `{ chat, messages: [...] }` ascending createdAt.
    71→- `POST /api/chats/[id]/messages` body semua kolom opsional kecuali minimal type/body → simpan sender "me" status "SENT", update chat.lastMessageAt → `{ message }`.
    72→- `DELETE /api/messages/[id]` → `{ success: true }`.
    73→- `POST /api/simulate/progress` `{ chatId }` → status pesan "me" yang SENT → DELIVERED → `{ updated }`.
    74→- `POST /api/simulate/reply` `{ chatId }` → jika profile.awayEnabled && !storeOpen → simpan pesan dari kontak berisi awayText. Selain itu generate balasan via LLM (z-ai-web-dev-sdk, fallback daftar balasan statis jika error/timeout). SEKALIGUS: set pesan "me" berstatus SENT/DELIVERED di chat itu jadi READ. → `{ message }`.
    75→- `GET /api/contacts` → `{ contacts }` (semua kolom).
    76→- `PATCH /api/contacts/[id]` `{ blocked?, name?, about? }` → `{ contact }`.
    77→- `GET /api/calls` → `{ calls }` desc createdAt.
    78→- `POST /api/calls` `{ contactId, kind: VOICE|VIDEO, direction: IN|OUT|MISSSED?->(pakai OUT), durationSec }` → `{ call }`.
    79→
    80→Pola client kirim pesan (WAJIB di ChatsView): POST message → tampil → setTimeout 900ms panggil `/api/simulate/progress` → setTimeout 2.5–5 dtk panggil `/api/simulate/reply` → refetch/append pesan + refresh daftar chat.

   102→- `PATCH /api/contacts/[id]/labels` `{ labelIds: string[] }` → `{ contact }`.

   109→- `GET /api/stats` → `{ totals: {sent, delivered, read, received, failed}, daily: DailyStat[] (14 hari asc), byType: {TEXT, IMAGE, AUDIO, ...} dari tabel Message, topChats: [{name, count}] 5 besar }`.
   110→- `GET /api/devices` → `{ devices }`. `POST /api/devices` `{ name, platform: WEB|DESKTOP|TABLET }` → `{ device }` (simulasi tautkan). `DELETE /api/devices/[id]` (bukan current) → `{ success: true }`.
   111→- `GET /api/privacy` → `{ profile }`. `PATCH /api/privacy` (hanya: lastSeen, onlineStatus, profilePhotoVis, statusVis, readReceipts, twoStepEnabled, blockedStrangers, notifMessages, notifGroups, notifCalls, notifPreview, notifSound). Nilai select: "everyone" | "contacts" | "nobody".
   112→- `GET /api/blocked` → `{ contacts }` (blocked=true). `PATCH /api/blocked/[contactId]` `{ blocked: boolean }` → `{ contact }`.
   113→- `GET /api/account` → `{ phoneNumber, autoBackup, backups, storage: { messageCount, mediaCount, estSizeKb } }`. `POST /api/account/change-number` `{ newNumber }` → update phoneNumber & phone. `POST /api/account/backup` → buat ChatBackup (hitung pesan) → `{ backup }`. `POST /api/account/restore` → `{ restoredMessages }` (angka besar simulasi). `PATCH /api/account` `{ autoBackup: off|daily|weekly|monthly }`. `POST /api/account/delete` → HANYA simulasi, jangan hapus data → `{ success: true }`.
